## 3. RTK 能力结论（闸门 A 关键证据）

- [ ] **支持 RTK_FIXED**
- [ ] 仅支持 RTK_FLOAT

| 状态 | 样本数 | 占比 |
| --- | --- | --- |
| RTK_FIXED | _待确认_ | _待确认_ |
| RTK_FLOAT | _待确认_ | _待确认_ |
| DGPS | _待确认_ | _待确认_ |
| GPS | _待确认_ | _待确认_ |
| NO_FIX | _待确认_ | _待确认_ |

**判定规则**（对应需求 FR-01）：

- 任一场景中 `RTK_FIXED` 占比 **≥ 70%** → 可进入阶段 B
- `RTK_FIXED` 占比 30%-70% → 需要在阶段 B 评估是否扩到全路段或引入补偿
- `RTK_FIXED` 占比 < 30% 或全部为 GPS → **不通过闸门 A**，返回评审
